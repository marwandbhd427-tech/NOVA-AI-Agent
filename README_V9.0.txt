NOVA V9.3 UNIVERSAL AGENT
==========================

الفكرة:
NOVA لم يعد يحتاج من المستخدم حفظ أوامر داخلية. طبقة Universal Agent تفهم الطلب الطبيعي وتحوّله إلى المسار التنفيذي المناسب.

المسارات:
- سؤال عادي -> Language Engine
- بحث صريح -> Web Search
- إنشاء لعبة/برنامج/تطبيق/مشروع -> Autonomous/Workspace Project Agent
- تعديل مشروع -> Workspace/Edit Agent
- تشغيل المشروع -> Runtime Agent
- اختبار المشروع -> QA/Project Tests
- عرض الملفات -> Project Tree
- إنشاء ملف/مجلد -> File Command Agent داخل workspace_files
- الذاكرة والمهام والأدوات المحددة -> الأنظمة الحالية

مبادئ V9:
1. الأدوات الحتمية لها الأولوية على التخمين اللغوي.
2. التصنيف المحلي أولًا لتقليل استهلاك Groq.
3. لا يتم إرسال كل سؤال عادي إلى LLM مرتين.
4. إنشاء المشاريع يمر عبر الاختبار والإصلاح الموجودين في النظام.
5. البحث الموسيقي يحتفظ ببوابة الأدلة ولا يختار من مصدر واحد.
6. مسارات الملفات الجديدة محصورة داخل workspace_files.
7. إذا كانت المعلومة أو المسار غير واضح، NOVA لا يخترع اسم ملف أو مشروع.

إصلاحات V9.3:
- السؤال العادي لا يسقط إلى Code Agent.
- نوع المشروع يُحسم قبل التوليد.
- تطبيق الملاحظات له بنية ثابتة ولا يمكن أن يتحول تلقائيًا إلى لعبة.
- أسماء المشاريع المعروفة حتمية.
- توسيع التعرف على صيغ «اعمل لي/انشئ لي/اصنع لي».

تشغيل:
python main.py
python main.py --gui
